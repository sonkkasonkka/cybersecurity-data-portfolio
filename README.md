# Cybersecurity Portfolio
This repository contains my cybersecurity practice labs and learning projects.

I am a cybersecurity student, and these works show my practical experience with web security, network security, malware analysis, reverse engineering, Linux, Windows, and basic security tools.
All labs were completed in controlled academic or training environments.

### Security Fundamentals
Basic Linux and Windows security practice:
- Linux users, groups, permissions and password hashes
- Windows access control and local security policies
- SSH, SCP and GPG
- Basic buffer overflow analysis

### Web Security
Practice with web application security:
- Active reconnaissance
- SQL Injection
- Command Injection
- XSS and CSRF
- IDOR and access control issues
- XXE and insecure deserialization

### Network Security
Practice with computer network security:
- Wireshark and tcpdump traffic analysis
- Nmap network scanning
- DHCP security
- Firewall access policies
- DNS analysis
- Snort IDS

### Reverse Engineering and Malware Analysis
Practice with reverse engineering and malware analysis:
- Machine code analysis
- Cuckoo Sandbox
- Malware network traffic analysis
- Malware configuration and memory analysis
