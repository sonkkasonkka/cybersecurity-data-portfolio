# Web Application Testing

Academic projects focused on investigating web application behaviour, checking access control, and documenting technical findings.

I used Burp Suite to inspect HTTP requests and responses, modify parameters and cookies, and observe how applications handle different inputs and user permissions.

## Practical work

- Inspected requests, responses, URL parameters, and cookies.
- Checked authentication and authorisation behaviour.
- Tested access to user data and restricted functions.
- Investigated input validation issues in training applications.
- Documented test steps, screenshots, observed results, and recommendations.

These exercises helped me practise reproducing application behaviour, investigating technical issues, and explaining findings in written reports.

**Tools and platforms:** Burp Suite, PortSwigger Web Security Academy, browser developer tools.
