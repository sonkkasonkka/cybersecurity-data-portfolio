# Network Diagnostics and Security

Academic projects focused on network connectivity, DNS, traffic analysis, and network services.

I worked with virtual machines to establish connections, capture traffic, inspect packets, and document network behaviour.

## Practical work

- Checked connectivity between hosts using ping.
- Investigated DNS queries, responses, and records using nslookup.
- Captured and filtered traffic with Wireshark and tcpdump.
- Analysed ICMP, ARP, and TCP communication.
- Inspected active connections, listening ports, and network services.
- Used Nmap to identify hosts, ports, and services.

These exercises helped me understand how devices communicate and how network checks can support the investigation of connection problems.

**Tools:** Wireshark, tcpdump, nslookup, Nmap, netcat, netstat, iperf, Cisco Packet Tracer.
