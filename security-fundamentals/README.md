# Operating Systems and Access Control

Academic projects focused on Windows and Linux user accounts, permissions, security policies, and secure remote access.

I configured accounts and access settings, checked their effects, and documented the results.

## Practical work

- Created users and groups in Windows and Linux.
- Configured file and folder permissions.
- Checked effective permissions and permission inheritance.
- Worked with password policies and access restrictions.
- Configured Windows auditing and reviewed recorded events.
- Established SSH connections between Linux virtual machines.

These exercises helped me understand how account settings and permissions affect access to files, systems, and services.

**Tools:** Windows administration utilities, Event Viewer, Process Explorer, Linux command line, SSH, VMware.
