# Database and SQL Practice

Academic projects focused on querying and managing relational databases in Microsoft SQL Server.

I worked with a database containing students, rooms, and hostels, using SQL to retrieve related information, apply conditions, and summarise records.

## Practical work

- Retrieved and filtered data using SELECT and WHERE.
- Combined related tables using JOIN.
- Counted and grouped records using aggregate functions and GROUP BY.
- Wrote subqueries and created views and stored procedures.
- Used constraints and triggers to implement database rules.
- Created database users, assigned roles, and managed permissions.

These exercises helped me understand how data is stored, connected, retrieved, and restricted through access permissions.

**Tools:** Microsoft SQL Server, Transact-SQL.
